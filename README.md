# PicklePop! — Purple Name Picker PWA

A playful, mobile-friendly name picker and group maker. All files are in the repository root.

## Features
- Random name picker with animated winner reveal and confetti
- Optional no-repeat mode until every name has been selected
- Paste or type names (one per line), shuffle, clear, import and export a text list
- Create balanced groups by number of groups or people per group
- Reshuffle, copy, and clear generated groups
- Automatically saves names and groups in the current browser using local storage
- Installable PWA with offline caching

## Publish with GitHub Pages
1. Download and unzip this package.
2. Open your GitHub repository and upload **all four app files plus this README** directly into the repository's main/root area. Do not place them inside another folder.
3. Commit the files.
4. In your repository, open **Settings → Pages** and publish from your `main` branch and `/(root)` (or use your existing GitHub Actions Pages setup).
5. Open the published site using its HTTPS GitHub Pages URL.

## Use
- Enter or paste names in the Name collection box, one per line, then tap **Save names**.
- Tap **Pick a name** for a random selection.
- To make groups, choose whether the amount means number of groups or people per group, enter the number, and tap **Create groups**.

## Notes
- No account or server/database is required.
- Names and groups are saved locally in the browser on that device. They do not automatically sync to another device or browser.
- To reset saved data, use the Clear button in the app or clear the site's browser storage.
- For PWA installation, open the published HTTPS site in your browser and choose **Add to Home screen** / **Install app**.
